# Fixture PDFs

Generated by `packages/pdf/src/fixtures.ts`. Regenerate with `bun run fixtures` and commit the result.
`packages/pdf/src/fixtures.test.ts` fails if these files drift from the builders.

| File | What it exercises |
|---|---|
| `rotated-90.pdf` | A4 with `/Rotate 90` (shown landscape) |
| `rotated-270.pdf` | A4 with `/Rotate 270` (shown landscape) |
| `cropbox-offset.pdf` | Letter MediaBox with a CropBox at (54, 72); page 2 is also `/Rotate 90` with a CropBox at (36, 90) |
| `mixed-sizes.pdf` | A4 portrait, US Letter, A4 landscape (MediaBox) and A4 `/Rotate 180` in one document |
| `scanned.pdf` | Two image-only pages with no text layer, like a scanner produces |

Every non-scanned page shows a 10% grid, an upright `TOP-LEFT` marker and a `BOTTOM-RIGHT` marker,
all in the **displayed** frame.

## Manual check in the field editor

1. Upload a fixture, create an envelope and add a signer.
2. Place a Signature field in a grid cell near `TOP-LEFT`, and one near `BOTTOM-RIGHT`.
3. Complete the envelope. In `signed.pdf` the signatures must sit in the same grid cells and read
   upright.

The automated version of step 3 is the "stamping lands where the editor shows the field" suite in
`fixtures.test.ts`. It stamps every page of every fixture, multiplies the image's `cm` matrices from
the content stream, and checks with an independent display transform that the image is inside the
field, centred and upright.
